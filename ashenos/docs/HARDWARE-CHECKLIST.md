# Проверка AshenOS на железе

Чек-лист для первого запуска образа на Raspberry Pi 4 с экраном Waveshare 4,3″ DSI (800×480)
и клавиатурой Rii mini X1. Отмечайте пункты по порядку: если ломается ранний шаг, дальше обычно
можно не идти — сначала чиним его.

Что понадобится: Pi 4 (2 ГБ ОЗУ и больше), карта microSD от 16 ГБ, блок питания 5 В 3 А,
экран Waveshare 4,3″ DSI, USB-клавиатура (или Rii mini X1), второй компьютер в той же сети (для SSH).

## 0. Сборка и запись

- [ ] `sudo ./build/build-image.sh` завершился строкой `==> Готово: …img` без ошибок
- [ ] В логе нет `error: target not found` от pacman (иначе в `packages.txt` неверное имя пакета)
- [ ] Образ записан: `sudo dd if=ashenos.img of=/dev/sdX bs=4M status=progress conv=fsync`

## 1. Загрузка и экран

- [ ] Красный светодиод горит, зелёный мигает — загрузчик видит карту
- [ ] На DSI-экране есть картинка (оверлей `vc4-kms-dsi-waveshare-800x480` из `boot/config-ashenos.txt`)
- [ ] Картинка не перевёрнута и не сдвинута; если перевёрнута — `ashenos-settings set ROTATION …` и `ashenos-settings apply`
- [ ] Тач реагирует на касания (если у вашей версии экрана есть тач)
- [ ] Время от включения до экрана входа: ______ с (норма для Pi 4 — до 60 с)

## 2. Первый запуск (`ashenos-firstboot`)

- [ ] `systemctl status ashenos-firstboot` — `active (exited)` без ошибок
- [ ] `journalctl -u ashenos-firstboot -b` — нет строк `Traceback` и `command not found`
- [ ] Повторная загрузка не запускает first-boot снова (сервис отработал один раз)

## 3. Вход и рабочий стол

- [ ] SDDM показывает экран входа в тёмной теме, экранная клавиатура появляется на поле пароля
- [ ] Вход пользователем `alarm` проходит, Plasma стартует на Wayland (`echo $XDG_SESSION_TYPE` → `wayland`)
- [ ] Цветовая схема `AshenOS`, шрифты Inter / JetBrains Mono
- [ ] Значки — тема **Ashen** (пепельные объёмные). Проверить: Параметры системы → Значки, или
      `kreadconfig6 --file kdeglobals --group Icons --key Theme` → `ashen`
- [ ] Обои применились (по умолчанию `waves`)
- [ ] Масштаб интерфейса читаемый на 800×480 (`SCALE` в `settings.conf`: 1 или 1.25)

## 4. Ввод

- [ ] Раскладки us/ru переключаются Alt+Shift
- [ ] Maliit (экранная клавиатура) появляется в полях ввода на рабочем столе
- [ ] Rii mini X1: тачпад двигает курсор, клик работает

## 5. Сеть и связь

- [ ] Wi-Fi: подключение через трей NetworkManager
- [ ] `ssh alarm@ashenos.local` (или по IP) пускает
- [ ] Bluetooth: наушники/клавиатура находятся и подключаются
- [ ] WayVNC — подключение к экрану с другого компьютера

## 6. Свои программы AshenOS

- [ ] `ashenos-settings list` печатает все ключи; `ashenos-settings set WALLPAPER lava && ashenos-settings apply` меняет обои
- [ ] `ashenos-settings` без аргументов открывает окно настроек (кнопка в меню приложений)
- [ ] `ashen-maps` открывается, тайлы OpenStreetMap грузятся при наличии сети
- [ ] В `ashen-maps` поиск адреса (Nominatim) и маршрут (OSRM) работают; без сети — понятное сообщение
- [ ] `claude-console` / приложение «Claude» запускает `claude` (нужен вход в аккаунт Anthropic)
- [ ] `ashenos-info` показывает версию, ядро и температуру

## 7. Нагрузка и питание

- [ ] Температура в простое: ______ °C (`vcgencmd measure_temp`), под нагрузкой: ______ °C (норма — до 80 °C)
- [ ] `vcgencmd get_throttled` → `throttled=0x0` (иначе слабый блок питания или перегрев)
- [ ] Свободная память на рабочем столе: ______ МБ (`free -m`)
- [ ] Время работы от аккумулятора кибердека: ______ ч

## Как сообщать о проблеме

Пришлите: номер пункта, что ожидалось и что произошло, и вывод
`journalctl -b -p warning --no-pager | tail -n 80`. Для экрана — фото.
