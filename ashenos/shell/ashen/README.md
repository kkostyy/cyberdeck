# Оболочка AshenOS на Quickshell

Перенос оболочки из `design/prototype` на Quickshell (sway). Под экран 800×480.

Сделано:
- **рамка** — чёрный безель вокруг экрана со скруглёнными внутренними углами;
- **верхняя полоса** — поиск приложений, точки рабочих столов, остров с заголовком окна,
  музыка, громкость, Wi-Fi, часы;
- **капля** — при наведении из рамки вытекает полоска с подробностями, по клику она
  раскрывается в панель (та же жидкая форма, что в прототипе, с теми же кривыми анимаций):
  календарь и часы, звук, музыка, сеть, поиск приложений;
- **фон** — тёмный градиент с медленно плывущими световыми дугами и волной под доком;
- **док** — закреплённые приложения (`~/.config/ashen/dock.json`, массив id `.desktop`-файлов),
  запущенные незакреплённые, точки у запущенных, пружинящее нажатие, подсказки;
  «Загрузки» и «Корзина»;
- **виджеты** — часы на точечном табло с карточкой даты, система (ЦП, ОЗУ, температура),
  плеер с крутящейся пластинкой; бегущие строки в стиле прототипа.

- **уведомления** — оболочка сама служит сервером уведомлений: новое вытекает каплей из острова,
  на острове счётчик, по клику на остров — список с «Очистить»;
- **погода** — open-meteo без ключа (`weather.py`); место берётся из `~/.config/ashen/config.json`
  (`{"lat":…,"lon":…,"city":"…"}`) или один раз определяется по IP и кешируется;
- **Bluetooth** — включение, сопряжённые устройства, подключение по клику;
- **экран блокировки** — как в прототипе; пароль проверяется через PAM (стек `login`),
  блокировка через 5 минут простоя, экран гаснет через 7,5 (не во время музыки).

- **индикаторы** — на клавиши громкости и яркости из рамки вытекает короткая полоска;
- **буфер обмена** — последние записи `cliphist`, клик копирует обратно;
- **раскладка и экранная клавиатура** — значок раскладки (клик — следующая) и кнопка `osk`;
- **скриншоты** — `ashen screenshot` (область, `--full`, `--edit` в satty): файл в
  `~/Pictures/Screenshots`, копия в буфере, уведомление.

- **настройки** (`ashen settings`, плитка в доке) — обои (картинки и видео, живые обои с паузой
  под окнами через `bin/ashen-autopause`), док, полоса, экран и сон, «не беспокоить», погода
  с поиском города, экранное время (сколько времени в каких приложениях, за 7 дней), о системе.
  Всё хранится в `~/.config/ashen/config.json`;
- **кнопка Claude** и кольца нагрузки системы на полосе.

## Команда `ashen` и клавиши

`bin/ashen` управляет оболочкой из терминала и из клавиш sway: `ashen toggle clock`, `ashen lock`,
`ashen volume raise`, `ashen brightness lower`, `ashen screenshot --edit` и т. д.
Готовые клавиши — в `sway/ashen-keys` (подключается `include` после остальных клавиш).

## Попробовать

```bash
./try.sh        # serpantinum → AshenOS; ещё раз — обратно
quickshell ipc -p shell.qml call ashen open clock true    # капля: clock | vol | music | net | bt | wx | notif | find
quickshell ipc -p shell.qml call ashen-lock lock          # заблокировать
quickshell ipc -p shell.qml call ashen-lock preview       # экран блокировки в окне, без блокировки
```
