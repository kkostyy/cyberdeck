# Оболочка AshenOS на Quickshell

Перенос оболочки из `design/prototype` на Quickshell (sway). Под экран 800×480.

Сделано:
- **рамка** — чёрный безель вокруг экрана со скруглёнными внутренними углами;
- **верхняя полоса** — поиск приложений, точки рабочих столов, остров с заголовком окна,
  музыка, громкость, Wi-Fi, часы;
- **капля** — при наведении из рамки вытекает полоска с подробностями, по клику она
  раскрывается в панель (та же жидкая форма, что в прототипе, с теми же кривыми анимаций):
  календарь и часы, звук, музыка, сеть, поиск приложений;
- **фон** — тёмный градиент с медленно плывущими световыми дугами и волной под доком;
- **док** — закреплённые приложения (`~/.config/ashen/dock.json`, массив id `.desktop`-файлов),
  запущенные незакреплённые, точки у запущенных, пружинящее нажатие, подсказки;
  «Загрузки» и «Корзина»;
- **виджеты** — часы на точечном табло с карточкой даты, система (ЦП, ОЗУ, температура),
  плеер с крутящейся пластинкой; бегущие строки в стиле прототипа.

Дальше: погода, Bluetooth, уведомления, экран блокировки.

## Попробовать

```bash
./try.sh        # serpantinum → AshenOS; ещё раз — обратно
quickshell ipc -p shell.qml call ashen open clock true    # открыть каплю: clock | vol | music | net | find
```
